# История изменений

## 21 ноября 2026 — OpenWebRX+ 1.2.131

- Сохранены файлы интерфейса и серверных компонентов действующей установки на Raspberry Pi после обновления OpenWebRX+.
- Восстановлена панель RIG: RUSW и DRMS, составное шумоподавление NR+/NF, управление отображением спектра и другие сохранённые элементы.
- В панель режимов добавлен BCFM. Кнопка DIG и список цифровых режимов расположены в строке HDR.
- Используется штатная реализация BCFM stereo из пакета; прежняя самодельная обработка FM stereo не возвращалась. Индикатор stereo ориентируется на различия каналов и не является детектором пилот-тона.
- Сохранены изменения буферизации аудио для браузерных обработчиков; устранение периодических прерываний при длительном прослушивании ещё необходимо проверить.
- Архив на NAS содержит полную копию установки и настроек; публичный репозиторий содержит код без конфигурации и учётных данных.

Файлы overlay предназначены для сверки с установленной версией, не являются самостоятельным дистрибутивом и не должны применяться без резервной копии. Не все ранее сохранённые файлы overlay обновлялись для 1.2.131.
